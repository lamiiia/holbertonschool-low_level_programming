# more_functions_nested_loops
- 0-isupper.c: function that checks for uppercase character (prototype: int _isupper(int c);).
- 1-isdigit.c: function that checks for a digit, 0 through 9 (prototype: int _isdigit(int c);).
- 2-mul.c: function that multiplies two integers (prototype: int mul(int a, int b);).
- 3-print_numbers.c: function that prints the numbers from 0 to 9, followed by a new line (prototype: void print_numbers(void);).
- 4-print_most_numbers.c: function that prints the numbers from 0 to 9 except 2 and 4, followed by a new line (prototype: void print_most_numbers(void);).
- 5-more_numbers.c: function that prints 10 times the numbers from 0 to 14, followed by a new line (prototype: void more_numbers(void);).
- 6-print_line.c: function that draws a straight line in the terminal (prototype: void print_line(int n);).
- 7-print_diagonal.c: function that draws a diagonal line on the terminal (prototype: void print_diagonal(int n);).
- 8-print_square.c: function that prints a square, followed by a new line (prototype: void print_square(int size);).
- 9-fizz_buzz.c: program that prints the numbers from 1 to 100, followed by a new line, with Fizz for multiples of three, Buzz for multiples of five and FizzBuzz for multiples of both.
- 10-print_triangle.c: function that prints a triangle, followed by a new line (prototype: void print_triangle(int size);).
- 100-prime_factor.c: program that finds and prints the largest prime factor of the number 612852475143, followed by a new line.
- 101-print_number.c: function that prints an integer (prototype: void print_number(int n);).
