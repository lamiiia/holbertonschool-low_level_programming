# Simple Calculator

A simple command-line calculator written in C.

## Description

The program shows a menu, asks the user to choose an operation (add, subtract,
multiply, divide or quit), then asks for two integers and prints the result.

## Compilation

    gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator

## Usage

    ./calculator

## Files

- calculator.c: source code of the calculator.
