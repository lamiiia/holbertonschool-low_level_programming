# hello_world

- 0-preprocessor: runs the C file stored in $CFILE through the preprocessor and saves the result into the file c.
- 1-compiler: compiles the C file stored in $CFILE without linking, and saves the output in a file with the same name but with the .o extension.
- 2-assembler: generates the assembly code of the C file stored in $CFILE and saves it in a file with the same name but with the .s extension.
- 3-name: compiles the C file stored in $CFILE and creates an executable named cisfun.
- 4-puts.c: C program that prints exactly "Programming is like building a multilingual puzzle, followed by a new line, using puts.
- 5-printf.c: C program that prints exactly "with proper grammar, but the outcome is a piece of art,", followed by a new line, using printf.
- 5-printf.c: C program that prints exactly "with proper grammar, but the outcome is a piece of art,", followed by a new line, using printf.
- 6-size.c: C program that prints the size of various types (char, int, long int, long long int, float) on the computer it is compiled and run on.
- 100-intel: generates the assembly code (Intel syntax) of the C file stored in $CFILE and saves it in a file with the same name but with the .s extension.
